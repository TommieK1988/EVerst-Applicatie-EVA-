03

AlertDialog

Modaal venster voor onomkeerbare beslissingen. Backdrop met blur. 440px breed. Default focus op de Cancel-knop (safety). Destructieve actie altijd rechts. Bij standaard "Weet je het zeker?" altijd het object benoemen ("Verwijder dossier D-1402").

Destructive · "Weet je het zeker?"

Dossier D-1402 verwijderen?
Het dossier, gekoppelde calculaties en bestanden worden permanent verwijderd. Deze actie kan niet ongedaan worden gemaakt.
Dossier D-1402 verwijderen?
Permanent — kan niet ongedaan worden gemaakt.

Warning · niet-destructief, wel waarschuwen

Opgeslagen wijzigingen verlaten?
Er zijn 8 niet-opgeslagen wijzigingen in deze calculatie. Als je nu sluit gaan deze verloren.
Drie-actie patroon (sluiten, annuleren, opslaan) is OK bij verlaat-flows. Voor alle andere alert-dialogs: max twee acties — annuleren (links) + bevestigen (rechts). Radix <AlertDialog> wikkelt automatisch focus-management en ESC-handling.

Use-cases · EVA-specifiek

Lege calculatie
Nog geen calculatieregels
Voeg een regel toe of selecteer een sjabloon uit de bibliotheek.
Lege planning
Nog niets gepland deze week
Sleep een activiteit uit de "Opdrachten" lijst naar een medewerker en datum om in te plannen.
3 regels voor goede empty states:
1. Bevestig dat het bewust leeg is (niet "Error: 0 results")
2. Leg uit waarom of wat ze kunnen doen
3. Geef een directe CTA naar de hoofdactie
Tone: bij lege "Goed bezig"-states (taken/herinneringen leeg) gebruik je positieve copy. Bij lege features (nog niets aangemaakt) is het uitnodigend.
