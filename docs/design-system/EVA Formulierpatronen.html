EVA · Design System · 6 · Formulierpatronen

Hoe EVA data invoert.

Zes formulierpatronen die door alle 140 schermen lopen: het label-input-helper trio, FormSection als groepering, Zoekveld, Combobox (RelatieZoekveld, MateriaalZoekveld), DatePicker en FilesUpload. Onderaan een volledig samengesteld formulier.

01

Form layout · label + input + helper

Elk formulierveld bestaat uit drie lagen: Label (verplicht-indicator *), Input (5 states), Helper/error tekst. De verticale volgorde is altijd hetzelfde — nooit placeholder als vervanging voor label.

03

Zoekveld · input met clear

Zoekicoon links, clear-knop rechts zodra er tekst is. Gebruikt in ⌘K-palette, filterbalk boven tabellen, materiaalzoekveld. Klik op het loepje opent ⌘K — klik in het veld typt direct.
